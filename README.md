# MURA

Интерактивный исторический атлас Казахстана. На карте работают три временных среза территории Казахского ханства. Границы представлены как **приблизительные исследовательские реконструкции**, а не как точные или бесспорные исторические границы. AI-ассистент пока не подключён.

## Локальный запуск

Требуется Node.js 20.9 или новее.

```bash
npm ci
npm run dev
```

Проверки перед коммитом:

```bash
npm run lint
npm run typecheck
npm run validate:data
npm run build
```

Для проверки собранной версии: `npm run start`.

Карта работает через MapLibre GL JS и базовый слой OpenFreeMap. Доступ к плиткам требует сети; атрибуция поставщиков отображается внутри карты. Ключ Gemini понадобится на следующем этапе и должен храниться только в серверной переменной `GEMINI_API_KEY`; образец находится в `.env.example`.

## Исторические данные

- Источник геометрий: [Seshat Global History Databank, Cliopatria](https://github.com/Seshat-Global-History-Databank/cliopatria), архив `cliopatria_polities_only_v021.geojson` версии 0.2.1, загружен 20 октября 2026 года. [Лицензия CC BY 4.0](https://github.com/Seshat-Global-History-Databank/cliopatria/blob/main/LICENSE.md).
- SHA-256 исходного ZIP: `e10a4e429fca708788ff9e7572a95fce801fae55852d217cffabc1c59cd4eed4`. Скрипт импорта отклоняет другой архив.
- Из исходного GeoJSON извлечены три записи `Kazakh Khanate`: 1468–1474, 1529–1555, 1721–1737. Геометрии оставлены без изменения координат; имена, ссылки на источник и маркировка точности добавлены в свойства. Скрипт `scripts/import-cliopatria.py` воспроизводит извлечение из исходного ZIP.
- Cliopatria прямо предупреждает, что её карты отражают одну версию границ, а историческая датировка и территория могут быть предметом спора. Поэтому приложение показывает статус «Реконструкция» и предупреждение о приблизительности.
- В трёх `events.geojson` описаны 12 событий: даты и краткие оригинальные пересказы, ссылки на источники, пометки о спорных датировках и связях с шестью персонами из `src/data/figures.ts`. Права на тексты порталов сохранены за их авторами; тексты и изображения в атлас не копировались.
- События без надёжной точки имеют `geometry: null` и доступны в списках и акцентах эпохи. Единственный исторический маркер относится к курултаю в Ордабасы: это **приблизительная** координата современного монумента «Бірлік», а не установленная точка собрания 1726 года. Источник координаты указан отдельно от источников события.
- Для Буланты и Аныракая показаны интервалы дат: доступные материалы расходятся в датировке. Карточки объясняют неопределённость и дают ссылки на использованные страницы и учебник.
- Режим «Проверить слои и маркер» использует **искусственные координаты**. Он служит только для проверки архитектуры слоёв и не обозначает историческую территорию или событие.

Метаданные периодов и источников находятся в `src/data/atlas.ts`, типы в `src/lib/atlas/types.ts`. Локализуемые поля имеют структуру `{ ru, kk?, en? }`; сейчас содержательные описания опубликованы по-русски, переводы можно добавить без изменения схемы. `npm run validate:data` проверяет годы, геометрию, происхождение координат, ссылки на источники, связи событий и персон, акценты и отдельность технических данных. Проверка отдельных GeoJSON повторяется перед показом в браузере.
