# MURA

Интерактивный исторический атлас Казахстана на казахском, русском и английском языках. На карте работают три временных среза территории Казахского ханства. Границы представлены как **приблизительные исследовательские реконструкции**, а не как точные или бесспорные исторические границы. Исторический гид доступен при настройке серверного ключа Gemini.

## Локальный запуск

Требуется Node.js 20.9 или новее.

```bash
npm ci
npm run dev
```

Проверки перед коммитом:

```bash
npm run lint
npm run typecheck
npm run validate:data
npm run validate:i18n
npm run test:guide
npm run build
```

Для проверки собранной версии: `npm run start`.

Карта работает через MapLibre GL JS и базовый слой OpenFreeMap. Доступ к плиткам требует сети; атрибуция поставщиков отображается внутри карты.

## Локализация

Переключатель KK / RU / EN меняет интерфейс, события, персон, подписи карты и контекст гида. Выбор языка сохраняется в `localStorage` и cookie `mura-locale`; cookie позволяет сразу отдать страницу на выбранном языке. Переключение языка не меняет выбранный период, событие, персону или положение карты. Исторические GeoJSON и каталог ссылок остаются без изменений.

Тексты интерфейса находятся в `src/data/ui-translations.ts`, переводы исторических описаний и заголовков источников в `src/data/historical-translations.ts`. Ссылки в карточках и ответах гида строятся из каталога `src/data/atlas.ts`; перевод заголовка источника не выдаётся за оригинальное название страницы. `npm run validate:i18n` проверяет полноту ключей и ID, структуру исторических полей и сохранение чисел в датах. Казахские и английские исторические формулировки требуют экспертной языковой и исторической редакции перед окончательной публикацией.

## Исторический гид

Гид работает через серверный маршрут `/api/guide` и модель `gemini-3.5-flash-lite`. Для настоящих ответов создайте ключ в [Google AI Studio](https://aistudio.google.com/app/apikey), затем добавьте в **неотслеживаемый** файл `.env.local` в корне проекта строку `GEMINI_API_KEY=ваш_новый_ключ`. Не помещайте ключ в `.env.example`, клиентский код или Git. После изменения `.env.local` перезапустите сервер. При деплое задайте ту же переменную в настройках окружения Vercel.

Сервер передаёт Gemini вопрос, выбранные эпоху/событие/персону, до четырёх предыдущих реплик и проверенные краткие материалы этой эпохи. Приложение не записывает беседы в базу данных; обработка отправленных данных провайдером зависит от его действующих условий. Не вводите персональные или секретные данные. Ответы на казахском языке генерируются на основе преимущественно русскоязычных материалов и требуют проверки перевода.

Ссылки в ответе строятся **только сервером** по ID из каталога `src/data/atlas.ts`. Ответ без допустимых ссылок отклоняется; при нехватке данных гид сообщает об этом. Это не является автоматической проверкой истинности каждого предложения: исторические утверждения и переводы требуют редакторской проверки. Ограничены размер запроса и ответа, есть таймаут 30 секунд и локальный для процесса лимит 10 запросов в минуту. Для публичной нагрузки нужен общий лимит на уровне платформы. Запустите `npm run test:guide` для проверки контракта запросов и отклонения вымышленных ссылок.

## Исторические данные

- Источник геометрий: [Seshat Global History Databank, Cliopatria](https://github.com/Seshat-Global-History-Databank/cliopatria), архив `cliopatria_polities_only_v021.geojson` версии 0.2.1, загружен 20 октября 2026 года. [Лицензия CC BY 4.0](https://github.com/Seshat-Global-History-Databank/cliopatria/blob/main/LICENSE.md).
- SHA-256 исходного ZIP: `e10a4e429fca708788ff9e7572a95fce801fae55852d217cffabc1c59cd4eed4`. Скрипт импорта отклоняет другой архив.
- Из исходного GeoJSON извлечены три записи `Kazakh Khanate`: 1468–1474, 1529–1555, 1721–1737. Геометрии оставлены без изменения координат; имена, ссылки на источник и маркировка точности добавлены в свойства. Скрипт `scripts/import-cliopatria.py` воспроизводит извлечение из исходного ZIP.
- Cliopatria прямо предупреждает, что её карты отражают одну версию границ, а историческая датировка и территория могут быть предметом спора. Поэтому приложение показывает статус «Реконструкция» и предупреждение о приблизительности.
- В трёх `events.geojson` описаны 12 событий: даты и краткие оригинальные пересказы, ссылки на источники, пометки о спорных датировках и связях с шестью персонами из `src/data/figures.ts`. Права на тексты порталов сохранены за их авторами; тексты и изображения в атлас не копировались.
- События без надёжной точки имеют `geometry: null` и доступны в списках и акцентах эпохи. Единственный исторический маркер относится к курултаю в Ордабасы: это **приблизительная** координата современного монумента «Бірлік», а не установленная точка собрания 1726 года. Источник координаты указан отдельно от источников события.
- Для Буланты и Аныракая показаны интервалы дат: доступные материалы расходятся в датировке. Карточки объясняют неопределённость и дают ссылки на использованные страницы и учебник.
- Режим «Проверить слои и маркер» использует **искусственные координаты**. Он служит только для проверки архитектуры слоёв и не обозначает историческую территорию или событие.

Метаданные периодов и источников находятся в `src/data/atlas.ts`, типы в `src/lib/atlas/types.ts`. Исходные русскоязычные поля имеют структуру `{ ru, kk?, en? }`; переводы хранятся отдельно от геометрии и исходных записей. `npm run validate:data` проверяет годы, геометрию, происхождение координат, ссылки на источники, связи событий и персон, акценты и отдельность технических данных. Проверка отдельных GeoJSON повторяется перед показом в браузере.
